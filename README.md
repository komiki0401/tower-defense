# EMBERLINE — 薄明の防衛線

オリジナルの図形キャラクターで遊ぶ1ステージの横スクロール型タワーディフェンス。外部ライブラリ・画像・フォントへの依存はありません。

## 起動

Node.js 20以降があるWindows環境で、このフォルダーをPowerShellで開きます。

```powershell
npm start
```

ブラウザで http://localhost:5187 を開きます。インストール・ビルドは不要。停止は Ctrl+C。同じWi-FiのスマートフォンではPCのローカルIPアドレスのポート5187へアクセスします。必要に応じてWindowsファイアウォールでローカルネットワークを許可してください。

## 操作

- 下部のボタンをクリック／タップで出撃。PCでは 1 が剣士、2 が守り手、3 が射手です。
- 資金が時間で回復し、出撃時に消費されます。ユニットごとに再出撃の待ち時間があります。
- ユニットは自動前進・自動攻撃。守り手で前線を支え、後方から射手で攻撃しましょう。
- 右の敵城のHPが0で勝利、左の自城のHPが0で敗北。結果画面から再挑戦できます。
- 狭い画面では戦場を左右にドラッグしてスクロール。PCでは左右矢印キーも使えます。下端のバーは表示範囲です。
- 一時停止ボタン、または Space で停止／再開。別タブへの移動時も自動停止します。
- 出撃、攻撃、ダメージ表示、撃破の視覚演出を実装。音声はありません。

## 設定と拡張

- src/config.js: ユニットのHP・攻撃力・射程・移動速度・攻撃間隔・コスト・出撃待ち時間、資金回復、城HP、敵出撃編成を調整。
- src/engine.js: 描画から独立した戦闘シミュレーション。Battle にステージ設定を渡せます。
- src/main.js: 描画と入力。unit 関数でキャラクター、castle 関数で城の描画を変更できます。
- src/style.css: PC・スマートフォン向けレイアウト。
- tests/engine.test.js: npm test で戦闘ロジックを確認。

ユニットは UNITS に設定を追加し STAGE.unlocks にIDを登録します。敵編成は enemySequence で指定します。複数ステージや育成は未実装ですが、設定の選択や戦闘前の能力補正を追加できる構造です。

## GitHub Pages

index.html と src をリポジトリ直下から静的配信できます。相対パスを使用しているためプロジェクト配下URLに対応します。GitHub Pages の Deploy from a branch で対象ブランチの / (root) を選ぶ構成です。server.js はローカル開発専用です。

GitHub Pagesへの公開は、別途確認してから実施します。

## クラウド環境で開発を再開

Node.js 20以降とGitを使用します。Windows固有の依存はなく、Linux環境でも同じコマンドで動きます。

```sh
git clone https://github.com/komiki0401/tower-defense.git
cd tower-defense
git switch main
npm test
npm start
```

既存のチェックアウトを使う場合は、未コミットの変更がないことを `git status` で確認してから `git pull --ff-only origin main` を実行します。変更がある場合は、先にコミットするなどして保存してください。

クラウド側のプレビュー／ポート転送機能でポート **5187** を開きます。依存パッケージがないため `npm install` は不要です。開発作業は `git switch -c codex/作業名` でブランチを作って開始できます。

現在の実装範囲は1ステージ、3ユニット、自動戦闘、視覚演出、勝敗・再挑戦、レスポンシブUIです。テストは資金・待ち時間・勝利・敗北・遠距離攻撃・初期化を確認します。育成、複数ステージ、音声、セーブは未実装です。

認証情報や `.env` はGitに保存せず、必要になった場合はクラウド環境のシークレット機能で管理します。現在のゲームにシークレットや環境変数の設定は不要です。
